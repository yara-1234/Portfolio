# School Network Performance Dashboard

> An Arabic-first Power BI management dashboard for monitoring a multi-branch school network through one connected view of finance, branches, students, and teachers.

![General figures dashboard](./assets/overview.jpg)

## Project overview

School leaders often need to move between financial performance, branch operations, student outcomes, and workforce planning before they can answer a simple question: **how is the network performing, and where should attention go next?**

This project brings those perspectives together in a guided Power BI report designed for fast executive scanning and focused drill-down analysis. The interface is Arabic-first, with shared filters and dedicated pages for the main operating areas of the network.

## Dashboard pages

| Page | What it answers |
| --- | --- |
| General figures | What is the current financial and network-level picture? |
| Branches | How does performance vary across locations? |
| Students | What do enrollment, demographics, attendance, and GPA reveal? |
| Teachers | How is the teaching workforce distributed by experience, education, and salary? |

- **3.50** average GPA
- **88.9%** average attendance

## Key analytical capabilities

### Financial and network monitoring

The overview page combines revenue, expenses, profit, margin, branch count, and trend views so decision-makers can understand the network at a glance.

### Student performance and demographics

The student page presents gender distribution, class-level distribution, GPA, attendance, and age/grade-oriented views to make academic monitoring easier to explore.

### Teacher workforce analysis

The teacher page brings together headcount, gender, education level, experience, salary, and subject-related breakdowns to support workforce planning.

### Interactive exploration

Shared filters allow users to compare results by branch, academic year, grade, semester, gender, and nationality without leaving the report context.
